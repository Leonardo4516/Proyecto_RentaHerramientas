# 🖼️ Banners y Fondos de Sección (`assets/img/banners/`)

Coloca aquí imágenes panorámicas para:
- Banners de promociones del Marketplace.
- Fondos de cabecera (*Hero sections*).

### Recomendaciones:
- **Formatos:** WebP o JPG.
- **Dimensiones sugeridas:** `1920 x 600 px` o `1280 x 480 px`.
- **Peso:** Menos de 300 KB.
